# 变更记录

## 上一版真实状态

左侧菜单按 25 个路由的信息架构分组，但仍将大量页面作为独立菜单项展示；专业应用、企业画像、园区碳资产、报告中心、系统子页面等仍占据左侧导航。填报监控只有企业任务与数据缺口两个视图。

## V4 本轮修改

- routes.js 改为七个管委会一级模块和三个企业入口，旧路由通过 menuVisible:false 保留。
- 新增 data-management 与 system-management 两个统一入口，路由总数变为 27。
- 零碳指标管控增加零碳推演入口。
- 园区能碳监测增加园区总览及五个二级入口，企业画像和绿色权益与碳资产归入该模块。
- 填报任务监控重构为任务管理、进度监控、填报审核。
- 成果与验收重构为验收准备、零碳成果库、验收材料管理、报告中心、验收材料输出。
- 企业绿色服务改为专业服务门户，五个专业路由统一由门户进入。
- 企业画像改为共享事实聚合页面。
- 清理未使用的 ParkAssetsPage、旧 EnterpriseProfilePage 和本地 assetData。

## 当前真实状态

管委会菜单实际显示 7 个一级功能，企业菜单显示 3 个入口；27 条路由均可访问。npm run build 通过，全新浏览器上下文控制台无错误。
